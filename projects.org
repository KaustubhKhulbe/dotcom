#+title: Projects

Some of my previous and ongoing projects. 

* Ongoing Projects
*** RVipc
- RISC-V extension to allow piping information between physic RISC-V cores
- Uses a set of hardware FIFOs and a handshake protocol to establish communication
- Avoids the cache coherence latency and trap entry expense incurred by shared memory and pipes
- Currently modifying gem5 and writing kernel specific code to leverage hardware and software ipc

*** CPU-GPU Compression
- Reverse engineering current software-transparent compression mechanisms involved in sending workloads to GPU
- Retrieving compression information through side channels
- Implementing academica compression algorithms and benchmarking with for power, area, and performance analysis
- Attempting to introduce novel comrpession mechanisms and analyze power, area, and performance tradeoffs

* Completed Projects
*** RISC-V Operating System
- RISC-V Unix-like OS with paging, filesystem, devices, system calls, and a pre-emptive round robin scheduling
- Developed a virtio block driver, cryptography driver, and entropy driver
- Kernel supports pipes between processes and argument passing according to POSIX standards
- 2nd place in OS design competition in ECE department with 100+ teams

*** CUDA-based LeNet CNN Network
- Developed and optimized forward pass of LeNet CNN Network
- Designed and benchmarked with modern accelerator features such as streams and tensor cores using nsys and ncu
- Achieved lossless speedups of 70.45% from base trivial GPU implementation
- Used cuBLAS, half precision floating points, and constant memory on A100 GPUs to improve cache and SM usage
